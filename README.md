# FaIR Climate-Scenario Analysis

Scenario analysis using the FaIR reduced-complexity climate model to examine how emissions pathways translate into atmospheric concentrations, radiative forcing and global temperature outcomes.

## Approach

The project used the FaIR Excel implementation to compare climate pathways and interpret the relationship between emissions assumptions and long-run warming. The accompanying report explains the model outputs, assumptions and limitations in accessible analytical language.

## Attribution

FaIR is an established reduced-complexity climate model developed by the climate-science community. The workbook is included as the completed analytical artefact; the underlying model framework is not presented as original software authored for this project.
